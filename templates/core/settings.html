02 / GITHUB MERGING

Automatically merge approved PRs

Off by default. Requires automatic approval above. After the service formally approves and finishes publishing, merge only the reviewed commit with passing CI and a clean GitHub merge state. Conflicts or missing requirements leave the PR open with a reason on its job.
